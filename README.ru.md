Личная база знаний с достаточной структурой для первого дня: правила frontmatter, готовые заметки, проекты и сферы жизни, еженедельные и ежемесячные обзоры. Связи между заметками важнее папок; папки задают крупные разделы, а теги — дополнительные признаки.

Это **публичный шаблон**, отдельный от личного vault автора. Улучшения иногда переносятся сюда вручную. Вводная документация доступна на русском и английском; внутри заметок и шаблонов используются оба языка.

## Начало работы

1. Клонируйте шаблон:

   ```sh
   git clone https://github.com/IgorKramar/obsidian-second-brain-template.git my-vault
   cd my-vault
   git remote remove origin
   ```

   Удаление remote шаблона не даст будущему push отправиться в этот публичный репозиторий. Для Git-синхронизации добавьте **собственный приватный репозиторий** до внесения личных данных.

2. Откройте `my-vault` в Obsidian через **Открыть папку как хранилище**.
3. Просмотрите конфигурацию и включите сторонние плагины, если доверяете ей. Установите их через **Настройки → Сторонние плагины → Обзор**: код плагинов в шаблон не входит.
4. Используйте список ниже. Настройки большинства плагинов уже находятся в [.obsidian/plugins/](.obsidian/plugins/).
5. В Folder Notes выберите **In the parent folder**. В Periodic Notes настроены папки Daily/Weekly/Monthly; оставьте поля шаблонов пустыми, чтобы работали готовые привязки Templater к папкам. Не применяйте один шаблон дважды.
6. Заполните [личный контекст](10-Areas/personal-context.md), [стратегию](10-Areas/strategy.md) и [семью](10-Areas/family.md) — это намеренно пустые заготовки.
7. Выберите любую тему: её файлы не включены. Исходное предпочтение автора — Obsidian gruvbox.

## Структура vault

| Путь | Содержимое |
|:---|:---|

Соединяйте мысли wikilink-ссылками. Добавляйте frontmatter для запросов Dataview. Заметки знаний должны хранить отдельные мысли и переживать конкретный проект; расширяйте структуру по мере реальной необходимости.

## Ежедневное использование

| Ритм | Практика |
|:---|:---|
| Каждый день · 5–7 минут | Заполнить дневную заметку; при необходимости записать здоровье в `10-Areas/health/metrics/` |
| Пятница · 15–20 минут | Подвести итоги рабочей недели и обновить `_ai-context/work-current-week.md` |
| Воскресенье · 10 минут | Посмотреть показатели здоровья и обновить `_ai-context/current-focus.md` |
| Конец месяца · 30 минут | Месячный обзор и финансовая сводка в `10-Areas/finance/monthly/` |
| Раз в квартал | Перечитать `10-Areas/strategy.md` и скорректировать направление |

В [руководстве по ритуалам](_meta/rituals.md) есть подробные шаги и повторяющиеся задачи Tasks. Этот ритм — отправная точка, его можно подстроить под себя.

## Пакет контекста

[Стартовый документ](_ai-context/claude-starter.md) с помощью встраивания Obsidian (`![[file]]`) собирает личный контекст, стратегию, текущий фокус и рабочую неделю. При необходимости откройте режим чтения и скопируйте отображаемый текст в новую сессию языковой модели.

Перед передачей просмотрите результат: заполненный vault может содержать личные сведения о семье, здоровье, финансах или работе. Передача контекста — отдельное явное действие, а не часть синхронизации хранилища.
